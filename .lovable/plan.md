# Publish the GPK holders manifest to all mirrors

The holders dropdown shows "Holders snapshot not published yet" because `manifests/gpk-topps-holders.json` is missing from every configured mirror. The app fetches this file from the same static mirrors that host the card images, so it must be generated and deployed alongside them.

## Step 1 — Generate the manifest locally

From the project root, run:

```bash
node scripts/build-holders-manifest.mjs
```

Expected output:
- `mirror-output/manifests/gpk-topps-holders.json`
- Console lines showing SA scope scan progress, AA page scan progress, and final totals.

Runtime is roughly 15–45 minutes, dominated by the SimpleAssets per-scope scan. The script is idempotent; kill and re-run any time.

## Step 2 — Publish `mirror-output/manifests/` to each mirror

The `manifests/` folder must end up at the root of each mirror host (same level as the image folders and `manifest.json`).

### Primary — GitHub Pages (`bewbzz/gpkonwaxbackup`)

Copy the generated folder into the repo you push to Pages:

```bat
copy /Y "C:\Users\User\Desktop\gpk-app-latest2\mirror-output\manifests\gpk-topps-holders.json" "C:\Users\User\Desktop\gpkonwaxbackup-repo\manifests\gpk-topps-holders.json"
```

If the `manifests` folder doesn't exist in the backup repo yet, create it first. Then commit and push as normal, and wait for the Actions tick.

### Backup A — Netlify

Deploy the same `mirror-output/manifests/` folder so that `https://gpkonwaxbackup.netlify.app/manifests/gpk-topps-holders.json` resolves. If your Netlify deploy is a drag-and-drop of the `mirror-output/` tree, just include the `manifests/` subfolder this time.

### Backup B — Cloudflare Pages

Deploy the same `mirror-output/manifests/` folder. Cloudflare's 25 MB file limit does not apply here — the holders JSON is small.

## Step 3 — Verify all three mirrors serve it

Run this from the project root once the deployments are live:

```bash
node -e "
const urls = [
  'https://bewbzz.github.io/gpkonwaxbackup/manifests/gpk-topps-holders.json',
  'https://gpkonwaxbackup.netlify.app/manifests/gpk-topps-holders.json',
  'https://gpkonwaxbackup.pages.dev/manifests/gpk-topps-holders.json',
];
Promise.all(urls.map(u => fetch(u).then(r => [u, r.status]).catch(e => [u, e.message])))
  .then(results => results.forEach(([u, s]) => console.log(s, u)));
"
```

You want `200` for all three. After that, refresh the app and open the holders dropdown — it will populate.

## Technical note

The holders manifest is intentionally separate from `gpk-manifest.json` (the image manifest). It is generated by `scripts/build-holders-manifest.mjs`, not by the image mirror build, and must be published manually the same way the images were.
